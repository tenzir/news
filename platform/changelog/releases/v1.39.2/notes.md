## 🔧 Changes

### On-demand stored schema loading in the Explorer

The Explorer now loads stored schemas on request and opens the **Results** tab by default. In **Stored data**, click **Load schemas** to retrieve schema names and event counts. Expanding a schema loads field definitions for all schemas once; further expansions reuse them until you click **Refresh**.

Schema lists and field definitions appear after loading completes, with **Retry** available if loading fails. Search now matches schema names only, and loading indicators are smaller.
